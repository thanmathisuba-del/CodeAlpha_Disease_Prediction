# Disease Prediction from Medical Data using Machine Learning

## 📌 Project Overview

This project was developed as part of my Machine Learning Internship at CodeAlpha.

The objective is to use machine learning classification algorithms to predict breast cancer conditions from medical data.

## 🎯 Objective

To build and evaluate machine learning models that can classify medical data into different disease conditions.

## 📊 Dataset

The Breast Cancer Wisconsin dataset was used for this project.

The dataset contains medical features related to breast cancer diagnosis.

## 🛠️ Technologies Used

- Python
- NumPy
- Pandas
- Matplotlib
- Scikit-learn
- Joblib
- Google Colab

## 🤖 Machine Learning Algorithms

Two classification algorithms were implemented:

1. Logistic Regression
2. Random Forest Classifier
